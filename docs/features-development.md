## 核心功能概述

### 指板与音准

- 0—24 品完整指板，支持预设/自定义调弦。
- 支持位置点击发声与音名详情揭晓。
- 隐藏模式下先选位置，再通过详情区域（或 Enter/空格）揭晓。
- 返回指板保留当前选中位置；刷新后清空练习位置。

### A1 听音挑战

- 题量支持 5/10/20。
- 以当前调弦 0—12 品绝对音高为题库，等音同判。
- 分数由基础分与辅助使用情况共同决定。
- 离开挑战上下文（切模式、切页、刷新等）后清空会话。

### 和弦

- 提供分类和弦目录与理论组成音展示。
- 支持根音选择、根音锁定、参考音阶联动。
- 支持实际指型候选、小图分页与筛选。
- 支持短音、持续音、琶音播放，并在多种中断场景释放声音。

### 音阶

- 提供 13 种音阶（含七声音阶/五声音阶/布鲁斯）。
- 主音、音阶、标签显示模式可切换。
- 支持单音试听与上行/下行/往返播放。
- 随机试听支持节奏组与 BPM 控制。

### 设置与共享状态

- 主题、调弦、音名显示、声音开关为跨页共享设置。
- 设置持久化到浏览器本地存储。
- 存储损坏、不兼容或不可用时回退到默认值。

### 路由

- 使用 hash 路由（如 `#/fretboard`、`#/scales`）。
- 支持直达链接、刷新、浏览器前进/后退。
- 未识别地址回退到默认页面，无需服务器重写规则。

## 主要源码目录与模块职责

### 页面与组件

- `src/pages/`：页面级容器（指板、和弦、音阶、设置与占位页）。
- `src/components/`：可复用界面（导航、调弦编辑、练习组件、和弦图示等）。
- `src/App.tsx`：应用壳层，组合路由与页面。

### 路由与设置

- `src/routes.ts`、`src/useHashPage.ts`：轻量 hash 路由与导航状态。
- `src/settings.ts`、`src/useAppSettings.ts`：设置定义、校验、持久化与共享。

### 听音挑战

- `src/challenge.ts`：题目规则、判分与统计基础逻辑。
- `src/challengeSession.ts`：挑战会话状态机与可取消流程。
- `src/components/EarChallenge.tsx`：A1 挑战界面与交互。

### 和弦与指型

- `src/chords.ts`：和弦目录、分类与理论信息。
- `src/fingeringTemplates.ts`：静态常用模板库。
- `src/fingerings.ts`：模板定位、约束校验与候选生成。
- `src/referenceScales.ts`：和弦页参考音阶与级数映射。
- `src/components/FingeringBrowser.tsx`、`src/components/FingeringDiagram.tsx`：候选浏览与 SVG 小图渲染。
- `src/pages/ChordsPage.tsx`：和弦页交互编排（根音锁定、候选切换、播放控制）。

### 音阶与音频

- `src/scales.ts`、`src/intervals.ts`：音阶公式、拼写与级数标签。
- `src/pitch.ts`：绝对音高/音名换算。
- `src/audio.ts`：基础拨弦合成与播放控制。
- `src/chordAudio.ts`：和弦短音/持续音/琶音播放。
- `src/holdGesture.ts`：短按/长按判定与取消流程。
