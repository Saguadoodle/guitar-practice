## 2026-10-15：音阶探索（C1）

### 交付范围

- 新增音阶页与导航顺序调整，保留 hash 地址结构（如 `#/scales`）。
- 支持 13 个音阶条目，覆盖七声音阶、五声音阶与布鲁斯分类。
- 引入主音控制、三种标签显示、完整指板高亮与单音试听。
- 实现上行/下行/往返播放、BPM 控制与音域提示。
- 新增 `check-scales.mjs` 与 `check-scale-audio.mjs` 自动检查。

### 历史检查记录

- 记录显示：`npm run lint`、`npm run build`、全部 13 个 `check-*.mjs` 脚本与额外深色回归通过。
- 记录显示：`git diff --check` 通过。
- 浏览器记录覆盖了音阶显示、播放停止、路由刷新、桌面与窄屏布局等。

## 2026-10-15：持续随机试听与自定义音程标签

### 交付范围

- 调整播放完成行为：正常结束仅清除临时高亮，不显示结束提示。
- 随机、上行、下行、往返与单音播放统一互斥，仅保留一个活动任务。
- BPM 输入支持键盘与步进，限制 60—300，非法输入反馈并禁用开始。
- 随机模式采用节奏组模型（含连音组），并约束小节内调度与跨帧恢复策略。
- 音阶标签统一到自定义音程体系（含 ♯IV / ♭V 等写法）并保持圆形标记样式。

### 历史检查记录

- 历史验收描述包含：不同 BPM 下试听速度、非法输入反馈、随机改速生效时机、切页停止、标签显示与主题/窄屏布局核对。
- 历史记录引用了调度 API 参考：
  - [MDN AudioScheduledSourceNode.start](https://developer.mozilla.org/en-US/docs/Web/API/AudioScheduledSourceNode/start)
