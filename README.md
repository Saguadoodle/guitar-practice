# Saguadlib

基于 React + TypeScript + Vite 的吉他练习工具。当前已完成七板块应用结构，并实现指板与音准、A1 听音挑战、和弦探索、C1 音阶探索等核心功能；完整规划见 [ROADMAP.md](ROADMAP.md)。

## 页面与功能概览

| 板块 | 当前状态 |
| --- | --- |
| 指板与音准 | 自由探索：0—24 品指板、调弦、点击拨弦与详情揭晓；听音挑战：5／10／20 题计分 |
| 音阶 | 13 种音阶、完整指板高亮、三种标签显示、单音／上下行试听 |
| 和弦 | 44 种类型、实际指型候选与小图、根音锁定、参考音阶、短音／持续音／琶音 |
| Jam Session | J1：可编辑和弦进行、轻摇滚鼓／贝斯／和弦、预备拍、循环及混音 |
| 扒谱 | 仅预留入口，需求待定 |
| 设置 | 主题、音名显示、声音开关、当前调弦、恢复默认 |
| 简介 | 占位，项目理念待提供 |

桌面使用导航栏，窄屏使用“板块导航”下拉框。地址使用 `#/fretboard`、`#/settings` 等 hash 路由，可直接访问并支持刷新与前进/后退；未识别地址回到指板页。

验收步骤：

1. 在自由探索关闭声音，再进入挑战，确认开始禁用且有启用声音按钮；启用后开始五题，第一题自动播放。
2. 确认提交前没有目标音名、八度、MIDI 或位置。重播不改辅助标记；点击辅助指板改变标记，却不揭晓或提交。
3. 选择音名并提交，核对对错、正确答案与本题得分。答案不能修改，不能重复提交，需点下一题继续。
4. 完成五题，核对分项与逐题记录，再测试重新开始和退出；10／20 题也可选择。
5. 挑战中改为 Drop D，确认当前练习结束并提示重开；离开“指板与音准”再返回也需要重新开始。
6. 在浅／深色与窄屏测试选项、辅助指板滚动；切回自由探索，检查 G2／C3 的详情揭晓与 24 品仍正常。

音效是否成功以浏览器 Web Audio 启动结果判断，网页无法检测扬声器硬件静音。请实际试听目标音和辅助音。音频不支持／恢复失败及待恢复播放的取消由检查脚本模拟验证。

## 和弦探索、锁定演奏与指型浏览

目录分为基础、七和弦、六和弦与附加音、扩展、变化五类，目前 44 种，包含本轮要求的类型及四种明确公式的变化组合；不宣称包含所有存在的和弦。组成音使用正确级数拼写，包括九／十一／十三度与重升、重降，例如 C13 = C、E、G、B♭、D、F、A，Cdim7 = C、E♭、G♭、B♭♭。add9 不包含七音，9 包含七音。

标题旁真正向下的箭头打开说明，默认收起。原来的常驻教学文字、指板图例与底部提示已移除。页脚继续使用 `1145141919810`。

### 选择根音与锁定

未锁定时单击完整指板的任意位置，设为根音并寻找包含该位置的常用模板，找到后自动播放。鼠标／触屏单击等待 350ms 以区分双击；键盘单击直接执行。双击当前根音位置锁定／解锁，并取消待执行的单击；锁定按钮提供手机和键盘的明确入口。

锁定后，大指板的点击只演奏该实际位置的单音，根音与指型不变。根音下拉框是明确改变根音的操作，会解除锁定；改变类型保留锁定。切换参考音阶、小图候选不会改变根音名称或锁定状态。调弦变化保持根音名称，并将无效的旧根音位置映射到附近同根音位置，重新生成候选、清除旧指型与声音。

参考音阶主音为当前根音，提供共享目录中的 16 个参考音阶（七声音阶、五声、布鲁斯、全音及两种减音阶）。包含完整和弦组成音的选项优先建议；可选其他音阶，页面会注明不完全包含。没有匹配建议时使用“仅相对根音级数”，不编造唯一调式。

锁定后的参考音阶视图使用实际调内三和弦性质：大三大写、小三小写、减三加 °、增三加 +；与音阶页共用计算。五声使用母音阶映射，布鲁斯附加音及音阶外音保留音名。未选参考音阶时显示常规相对根音音程，并明确标注；未锁定时始终显示音名。

### 实际指型与小图

- 已移除自由组合品位的枚举和旧缓存。现在只定位 79 个静态常用模板及其合理移调，每个模板记录品位、不弹弦、根音、1—4 指分配、实际横按范围、形状类别与允许省略的音。
- 标准调弦以 C／A／G／E／D 开放形状、常用 E／A 横按和局部形状为基础，不强求五种完整可移动形状。包含大／小、7／m7／maj7、sus、五度、6／m6，以及部分减和弦、半减七、9／maj9／m9、6/9、13／maj13／m11／m13、7♭9／7♯9 等紧凑按法。44 种理论类型并非都有指型模板。
- 降半音沿用形状，按实际音高定位，例如 B 大和弦可使用 x32010。Drop D 有 9 个明确适配模板，另可使用不弹第 6 弦的已验证标准模板。FACGCE 或不匹配支持音高的自定义调弦暂不显示指型，保留公式与锁定后的单音探索。
- 每弦最多一个音，只使用四指，不使用拇指。同指多音必须有同品横按；验证空弦冲突、手指品位冲突及跨度 ≤4（空弦不计）。模板来源与明确指法是准入依据，检查算法不等于人体工学证明。
- 点击大指板后只寻找包含精确根音位置的模板；没有则提示“该位置暂无常用指型”。类型或调弦不支持则提示“暂无已验证常用指型”，不补虚拟配音。
- 小图左 6 右 1，○ 空弦、× 不弹，按弦圆点和横按标明手指编号；根音双圈。六张分页，可按把位及选中根音筛选，开放形状和常见横按优先。计数仅代表模板定位结果。
- 小图、完整指板最明显高亮及播放共享同一个实际指型数据。切换小图不改变根音名称或锁定状态。
- 省略音由每个模板明确列出，例如 C13 省略五度和十一度，Cm11 可省略九度；实际音和省略音都显示，不能据此改写完整理论公式。

基础按法参考：[Fender B 和弦](https://www.fender.com/articles/chords/learn-to-play-the-b-chord-on-guitar)、[Fender Drop D](https://www.fender.com/articles/setup/drop-d-tuning-on-guitar)。扩展模板为手工整理并逐项检查的有限库，仍需真实手部试奏确认个人舒适度。

### 播放操作

单击“播放”发短音；按住超过 220ms 开始持续稳定音高，松开约 0.65 秒自然衰减。鼠标／触屏 Pointer Events、Enter／空格都支持；重复键不会重新触发持续音。短按和长按分别只触发一次声音，不靠重复拨弦延长。

“琶音 arpeggio”按第 6 弦到第 1 弦的实际发声位置逐个演奏，间隔 0.32 秒。短音复用已有拨弦波形；持续音使用同样泛音配比的连续振荡器和同一 MIDI 频率转换。总增益按声部数限制。

松开、移出／指针取消／捕获丢失、按钮失焦、窗口失焦／页面隐藏、换根音／类型／指型／调弦、静音、离开板块、停止播放均会释放或取消声音与尚未启动的琶音。播放失败显示提示，指板和候选仍可使用。

### 浏览器验收

1. 默认说明收起，点击向下箭头或按 Enter 打开并收起；确认原常驻文字不再出现。
2. 标准调弦，未锁定时点击 6 弦 0 品，根音 E；当前指型须包含此位置，最明显标记与各弦品位、小图一致。单击播放和琶音只听这些实际位置。
3. 双击该根音位置锁定，再点 6 弦 1 品，根音仍 E，只演奏 F2。切换参考音阶，检查调内和弦性质级数、内外音层次；按钮或双击解锁。
4. 鼠标按住播放约一秒再松开，测试移出、停止、失焦、切页和静音没有卡音；用键盘 Enter／空格也检查。真实手机上另行检查长按与取消。
5. 点候选小图，核对大指板实际位置变化、播放音一致、锁定未变；分页和仅含根音筛选的计数正确。
6. 选择 C13，核对理论七音与实际省略说明；比较 Cadd9 与 C9 的七音区别。高把位点击 1 弦 24 品，检查局部图起始品位、按弦位置和空弦／不弹标记。
7. 在设置中切换 Drop D，核对 D 的 000232；自定义第 6 弦 F♯2 后检查无已验证模板提示，并锁定根音试听单音；切换两主题并缩到约 375px，图示在下方、可以分页，完整指板内部横向滚动。

当前未做逆向识别或自动转位命名。候选库是有限常用模板的定位结果，不是所有可能指型或人手可演奏保证。

## 音阶探索（C1，2026-10-15）

导航顺序：指板与音准 → 音阶 → 和弦 → Jam Session → 扒谱 → 设置 → 简介。原 hash 地址保持，例如 `#/scales`，GitHub Pages 子路径和 workflow 未改变，刷新无需服务器路由。

音阶页有 13 个条目，按七声音阶／五声音阶／布鲁斯组织，中文与 English 同时显示。大调与 Ionian、自然小调与 Aeolian 合并；旋律小调按本轮约定采用爵士用法，上下行同一组音。和弦参考另保留全音及两种减音阶，共享 `src/scales.ts` 定义与 `src/intervals.ts` 的音程拼写和罗马级数。

主音只通过控件修改。0—24 品当前调弦指板高亮音阶内音，主音双圈、其他音实线圈、外音弱化；默认级数，可改音名或两者。小调五声使用自然小调母音阶级数 i、III、iv、v、VII。任何位置可试听单音，不改变主音。音阶与和弦各自保留页面内选择，跨页不会互相改动；刷新后练习选择恢复默认，共享偏好仍从本地存储恢复。

上行、下行、上行＋下行、随机均持续循环，再次点击当前按钮停止；切换模式先取消旧声音。每轮普通音阶仍覆盖完整八度，往返转折点不重复触发。BPM 输入 60—300，四分音符为一拍，所有模式为连续十六分音符；当前按钮有描边、粗体、“播放中”和 aria-pressed。更改主音／音阶／调弦、静音、失焦、切页都停止。指板点击仍为单次单音。

## Jam Session · J1 基础伴奏

进入 `#/jam` 可直接开始：A 自然小调，Am → F → C → G，每张一小节，4/4、90 BPM，基础轻摇滚，一小节预备拍后持续循环。再次点击播放按钮停止；关闭全局声音、离开板块或页面隐藏也会停止。共享吉他调弦与歌曲调性独立，换调弦不会把伴奏移调。

歌曲主音变化会按音程整体移调卡片，保留类型和时长；改变大调／自然小调不会覆盖进行。预设为大调 I–V–vi–IV、自然小调 i–VI–III–VII，或单和弦 I／i，需明确点击“应用预设”。卡片可新增、复制、删除、上移／下移；每张支持半／一／两小节。最多32张，总拍数必须为4的整倍数；无效时明确提示，绝不静默补拍。编辑中若暂时无效，已开始的旧进行继续，待应用的无效编辑不会替换它。

类型复用现有44类和弦与公式，按类别显示中英文名称。调外和弦允许播放并标记；只对能明确判断的调内三／七和弦显示级数，其他标“调内音组成 · 暂不标级数”，不猜测。少数罕见调性中需要重升／重降根音时，卡片使用可输入的等音根音，实际音高保持一致。

固定轻摇滚模板：八分踩镲，2／4拍军鼓，1／3拍底鼓加一个轻量切分；贝斯换和弦突出根音，辅以实际五音与八度；和弦在起拍与后半小节切分位置弹奏。半小节卡片会在对应拍点换和弦，两小节卡片延续同一和声。和弦用G3—G5附近的合成拨弦配音，保留共同音并就近移动；贝斯根音C2—B2、五音／八度最高B3。它不是吉他指型库。

BPM自由输入60—300，四分为一拍；三个声部各有自己的节奏，不使用音阶页的连续十六分规则。播放中有效BPM在下一小节生效，编辑进行在下一轮首小节生效，界面标注待应用。已提前排程但未开始的小节可撤回重排，避免边界前的修改漏出旧版本。鼓／贝斯／和弦各有音量与静音，另有Jam主音量；通过各声部总线立即平滑更新，包括已经开始和将要发声的音，最多约25ms短释放尾音。预备拍独立于鼓静音，受主音量和全局声音开关控制。

`src/jam.ts` 管进行、预设、移调与分析；`src/jamArrangement.ts` 管确定性编配与配音；`src/jamAudio.ts` 管音频时钟与混音；`JamPage`、`JamProgressionEditor`、`JamMixer` 分开管理界面。音效复用原拨弦合成和频率转换，鼓使用浏览器内确定性波形；没有新音频库或素材下载。所有声部和四拍／小节／当前和弦进度使用同一AudioContext时间线，定时器仅提前安排小节与刷新界面。暂停音频或页面严重中断会停音并提示，不假装仍播放或密集追赶。
